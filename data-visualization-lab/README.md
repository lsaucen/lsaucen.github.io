# Data Visualization Lab

Portfolio extension for data visualization roles.

## Projects

1. **Retail Performance Dashboard**  
   Executive view of revenue, target attainment, margin, region and product mix.

2. **Web Analytics Dashboard**  
   Sessions, engagement, acquisition channels, device behavior and content performance.

3. **Customer Retention Dashboard**  
   Cohort retention, churn by segment, retention trend and customer-risk distribution.

## Data provenance

All values in these demos are synthetic. They are intentionally separated from confidential client or employer data.

## Design approach

The pages are original portfolio demos built around common analytics-dashboard patterns: clear KPI hierarchy, a small number of decision-oriented visuals, explicit comparison points and responsive layouts.

Open-source dashboard repositories were reviewed as design references. No third-party project is represented as original client work.
